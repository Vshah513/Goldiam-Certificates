# Images folder

Drop your images here (logos, certificates, etc.). They will be served at `/images/your-file.png`.

**Usage in the app:**
- In JSX: `<img src="/images/logo.png" alt="Logo" />`
- In CSS: `background-image: url('/images/background.jpg');`

Supported formats: PNG, JPG, JPEG, GIF, WebP, SVG.
